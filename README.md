# Chess Soft Coach — шахматы с подсказками

Одностраничный сайт: шахматная доска, выбор стороны и **одна** подсказка — лучший ход по версии Stockfish 19 (NNUE, WebAssembly), прямо в браузере.

## Как открыть

Сайт использует Web Worker + WASM, поэтому из `file://` браузер его не запустит — нужен http(s).

Локально:

```bat
serve.bat
```

поднимает <http://127.0.0.1:8080> и открывает страницу.

Публично по https — см. «Публикация» ниже.

## Как это работает

1. Сверху кнопка **«Я играю за белых»**. Нажатие переключает сторону: становишься за чёрных, кнопка меняется на «Я играю за чёрных». Доска разворачивается твоей стороной вниз.
2. Ходы делаешь сам за обе стороны (перетаскиванием или кликом: фигура → поле).
3. Когда ход твой — показывается **ровно один ход**: тот, что движок считает лучшим. Он подсвечен на доске золотой стрелкой, в панели — его нотация, оценка и вариант продолжения. Кнопка «Сыграть этот ход» играет его сразу.
4. Когда ходит соперник — подсказка скрыта, чтобы решение за него принимал ты. Галочка «Подсказывать и за соперника» снимает ограничение.
5. «Сила анализа» — глубина поиска: 12 / 18 / 22 (по умолчанию) / 28.

Ещё: отмена хода, переворот доски, новая партия, копирование FEN, список ходов, шкала оценки, подсветка шаха и последнего хода. Пешка всегда превращается в ферзя автоматически — тост сообщает, во что превратилась.

## Что внутри

```
index.html              разметка страницы
manifest.webmanifest    имя/иконка для «установки на рабочий стол»
assets/style.css        тёмная тема
assets/app.js           вся логика: доска, ввод, рендер, подсказка
vendor/chess.js         правила шахмат (chess.js 1.4.0, BSD-2-Clause)
vendor/stockfish.js     обёртка движка (nmrugg/stockfish.js, GPLv3)
vendor/stockfish.wasm   Stockfish 19, lite-сборка, однопоточная (~1.8 МБ)
vendor/pieces/*.svg     фигуры cburnett (GPLv2+, из lichess)
```

Папка `_test/` — только для разработки (jsdom-тесты и cloudflared). На хостинг её выкладывать не нужно.

## Насколько сильные подсказки

Stockfish 19 с облегчённой NNUE-сетью в браузере — примерно 2800–3000 Elo на глубине 20+. Этого хватает, чтобы уверенно обыгрывать почти любого человека.

Магнуса Карлсена такая конфигурация **не гарантирует**: для этого нужен движок с полной сетью (94 МБ WASM или нативный) и глубина 30+. Здесь выбран компромисс — 1.8 МБ и загрузка за секунду, работа офлайн.

Хочешь максимум: положи в `vendor/` полную сборку (`stockfish-19-single.js` + `.wasm`) и поменяй путь к воркеру в `assets/app.js` — сайт потяжелеет до ~100 МБ.

## Публикация

Статика. Нужно выложить `index.html`, `manifest.webmanifest`, `assets/`, `vendor/`.

Варианты с бесплатным https:

- **GitHub Pages** — создать репозиторий, залить папку, включить Pages: `https://<логин>.github.io/<репозиторий>/`.
- **Netlify Drop** — перетащить папку на <https://app.netlify.com/drop>: получишь `https://<имя>.netlify.app`.
- **Cloudflare Pages** — то же самое, `https://<имя>.pages.dev`.
- **Свой домен** — купить/привязать к любому из сервисов выше.

Требование к серверу одно: `.wasm` должен отдаваться с `Content-Type: application/wasm` (все перечисленные умеют). Сжатие gzip/brotli уменьшит `stockfish.wasm` примерно вдвое.

Временный https-адрес без регистрации можно поднять туннелем:

```bat
cloudflared tunnel --url http://127.0.0.1:8080
```

он выдаст ссылку вида `https://<случайные-слова>.trycloudflare.com` — живёт, пока запущен процесс.
